# ¿Qué es AJAX?

**AJAX** (*Asynchronous JavaScript and XML*) es una técnica de desarrollo web que permite a las aplicaciones web comunicarse con un servidor de forma asíncrona sin necesidad de recargar la página completa.

## 🔹 Características principales:
- Permite actualizar partes de una página sin recargarla completamente.
- Utiliza tecnologías como:
  - **JavaScript** para gestionar la solicitud y respuesta.
  - **XMLHttpRequest** o **Fetch API** para la comunicación con el servidor.
  - **JSON** o **XML** como formatos de datos intercambiados.


# 🌐 Ejemplo de AJAX con API y jQuery

A continuación, te muestro cómo realizar una solicitud **AJAX** utilizando **jQuery** para obtener datos desde una API.

## 📌 Código de ejemplo:

```html
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>AJAX con jQuery</title>
    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
</head>
<body>

    <h2>Usuarios desde una API</h2>
    <button id="cargarDatos">Cargar Usuarios</button>
    <ul id="listaUsuarios"></ul>

    <script>
        $(document).ready(function(){
            $("#cargarDatos").click(function(){
                $.ajax({
                    url: "https://jsonplaceholder.typicode.com/users", // API de ejemplo
                    type: "GET",
                    dataType: "json",
                    success: function(data) {
                        $("#listaUsuarios").empty(); // Limpiar lista antes de agregar nuevos elementos
                        data.forEach(user => {
                            $("#listaUsuarios").append(`<li>${user.name} - ${user.email}</li>`);
                        });
                    },
                    error: function(error) {
                        console.error("Error en la solicitud:", error);
                    }
                });
            });
        });
    </script>

</body>
</html>

```
# Importante activar AJAK en wordpress
Esto lo debes pegar en tu archivo de encolamiento

```php
    // Pasar ajaxurl a tu script
    wp_localize_script('main-scripts', 'ajax_object', array('ajaxurl' => admin_url('admin-ajax.php')));

```

### Descripción:
1. wp_localize_script: Esta función de WordPress permite pasar datos desde PHP a JavaScript.

  - Parámetros:
    - 'main-scripts' → Nombre del script al que queremos asociar la variable (main-scripts.js en este caso).
    - 'ajax_object' → Nombre del objeto JavaScript que contendrá los datos.
    - array('ajaxurl' => admin_url('admin-ajax.php')) → Un array con los datos a pasar:
    - 'ajaxurl'       => admin_url('admin-ajax.php') → Genera la URL para procesar solicitudes AJAX en WordPress.

```PHP
  function crear_taxonomia_personalizada() {
      $labels = array(
          'name'              => _x('Categorías Personalizadas', 'taxonomy general name'),
          'singular_name'     => _x('Categoría Personalizada', 'taxonomy singular name'),
          'search_items'      => __('Buscar Categorías'),

          'parent_item'       => __('Categoría Padre'),
          'parent_item_colon' => __('Categoría Padre:'),
          'edit_item'         => __('Editar Categoría'),
          'update_item'       => __('Actualizar Categoría'),
          'add_new_item'      => __('Añadir Nueva Categoría'),
          'new_item_name'     => __('Nuevo Nombre de Categoría'),
          'menu_name'         => __('Categorías Personalizadas'),
      );

      $args = array(
          'hierarchical'      => true,  // True si quieres que se comporte como categorías, false si como etiquetas.
          'labels'            => $labels,
          'show_ui'           => true,
          'show_admin_column' => true,
          'query_var'         => true
      );

      register_taxonomy('categoria_personalizada', array('book'), $args);
  }
  add_action('init', 'crear_taxonomia_personalizada');
```

```PHP
    // Función para obtener las categorías personalizadas
    function obtener_categorias_personalizadas() {
        $categorias = get_terms(array(
            'taxonomy' => 'categoria_personalizada',
            'hide_empty' => false,
        ));

        if (!empty($categorias) && !is_wp_error($categorias)) {
            $opciones = '';
            foreach ($categorias as $categoria) {
                $opciones .= '<option value="' . $categoria->slug . '">' . $categoria->name . '</option>';
            }
            echo $opciones;
        }
        wp_die(); // Finaliza AJAX.
    }
    add_action('wp_ajax_obtener_categorias_personalizadas', 'obtener_categorias_personalizadas');
    // wp_ajax_nopriv_: Se usa cuando quieres que la función AJAX esté disponible para usuarios que no han iniciado sesión.
    add_action('wp_ajax_nopriv_obtener_categorias_personalizadas', 'obtener_categorias_personalizadas');
```

```PHP
// Función para buscar entradas por categoría personalizada
function buscar_entradas_por_categoria() {

    $categoria = $_POST['categoria'];

    $args = array(
        'post_type' => 'book',
        'tax_query' => array(
            array(
                'taxonomy' => 'categoria_personalizada',
                'field'    => 'slug',
                'terms'    => $categoria,
            ),
        ),
    );

    $query = new WP_Query($args);

 
    if ($query->have_posts()) {
        echo '<div class="row">';
        while ($query->have_posts()) {
            
            $query->the_post();
            $terms = get_the_terms(get_the_ID(), 'categoria_personalizada');

            echo '<div class="col-md-4">';
            echo '<article class="cardBook">';
           
            if ( has_post_thumbnail() ){
                echo '<div class="cardBook__icon">';
                the_post_thumbnail('img-tiendas');
                echo '</div>';
            }
            
            echo '<div class="cardBook__info">';
        
            if (!empty($terms) && !is_wp_error($terms)) {
                foreach ($terms as $term) {
                    echo '<div class="cardBook__category">'.esc_html($term->name).'</div>';
                }
            }
        
            echo '<h3 class="cardBook__title">';
            echo esc_html(the_title());
            echo '</h3>';
            echo the_excerpt();
            echo '<a href="'.get_the_permalink().'" class="button">Saber más</a>';
            echo '</div>';

            echo '</article>';
            echo '</div>';
        }
        echo '</div>';
    } else {
        echo '<div class="notSearch">No se encontró la categoría seleccionada.</div>';
    }

    wp_die(); // Finaliza AJAX.
}
add_action('wp_ajax_buscar_entradas_por_categoria', 'buscar_entradas_por_categoria');
add_action('wp_ajax_nopriv_buscar_entradas_por_categoria', 'buscar_entradas_por_categoria');

```
