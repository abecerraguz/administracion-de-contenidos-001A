# Semana 09 - Evaluación Final Transversal

**Proyecto integrador:** Blog Actualidad — Entrega final

> La evaluación final consiste en la entrega del sitio web completo desarrollado durante las 8 semanas del curso. Se trabaja de forma paralela desde la semana 6.

---

## Lista de verificación previa a la entrega

Antes de entregar revisa que tu proyecto cumple con todos los puntos:

### Estructura del tema
- [ ] `style.css` con meta información completa del tema
- [ ] `functions.php` organizado con `require_once` a archivos de `inc/`
- [ ] `index.php` con loop principal y sección de portafolio
- [ ] `single.php` con vista de detalle de entradas
- [ ] `page.php` con vista de páginas estáticas
- [ ] `archive.php` con vista de entradas por categoría
- [ ] `header.php` con `wp_head()` y menú de navegación
- [ ] `footer.php` con `wp_footer()`
- [ ] `sidebar.php` con entradas recientes
- [ ] `template-parts/` con al menos `content-card.php` y `content-sidebar.php`

### Contenido y funcionalidades
- [ ] Mínimo 5 entradas publicadas con imagen destacada, categoría y etiqueta
- [ ] CPT **Portafolio** con 3 proyectos y taxonomía `tipo-proyecto`
- [ ] CPT **Slider** con 3 slides usando campos ACF (subtítulo, URL y texto del botón)
- [ ] Menú de navegación con categorías y páginas
- [ ] Página estática *Sobre mí* o similar

### Diseño y responsividad
- [ ] Bootstrap integrado y funcional
- [ ] Diseño responsivo verificado en móvil, tablet y escritorio
- [ ] Paleta de colores y tipografía coherente con la identidad del sitio
- [ ] Imágenes optimizadas (no exceden 300kb)

### Despliegue
- [ ] Sitio publicado y accesible en el servidor cPanel
- [ ] URL funcional entregada al docente
- [ ] Base de datos migrada correctamente (sin referencias a `localhost`)
