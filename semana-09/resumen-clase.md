# Semana 09 - Evaluación Final Transversal

**Asignatura:** Administración de Contenidos

---

## Descripción

La semana 9 corresponde a la **Evaluación Final Transversal** de la asignatura. Esta evaluación se trabaja de manera paralela a las actividades de la Experiencia 3 (desde la semana 6). Consiste en el desarrollo de un sitio web completo con diseño personalizado utilizando WordPress instalado en un servidor web.

---

## Requisitos del Proyecto Final

- Instalación de WordPress en servidor web remoto
- Diseño personalizado del sitio (colores, tipografías, estilos visuales)
- Definición de secciones y estructura de navegación del sitio
- Uso de PHP para desarrollar funcionalidades específicas y personalizar la lógica del sitio
- Implementación de JavaScript para interactividad (menús desplegables, sliders, formularios)
- Optimización de rendimiento: imágenes, caché, minificación de CSS y JS
- Prueba en diferentes dispositivos y navegadores (diseño responsivo)
- Ajustes finales y entrega

## Competencias Evaluadas

- Evaluar la estructura de contenidos mediante mapa de navegación
- Instalar y configurar WordPress en servidor remoto
- Armar plantilla personalizada con criterios técnicos de diseño
- Implementar el sitio con CMS, framework CSS y preprocesadores
