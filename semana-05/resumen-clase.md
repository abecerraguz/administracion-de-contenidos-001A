# Semana 05 - Instalando WordPress en cPanel

**Experiencia:** 2 | **Asignatura:** Administración de Contenidos

---

## Introducción

Esta semana se aprende a subir el sitio WordPress a un servidor real utilizando cPanel. El proceso abarca desde la creación de la base de datos MySQL hasta la configuración del archivo `wp-config.php`, permitiendo gestionar el sitio web de manera autónoma en un hosting profesional.

---

## Temas Tratados

- ¿Qué es cPanel? Panel de control de hosting web
- Instalación de WordPress en cPanel paso a paso
- Configuración de la Base de Datos MySQL en cPanel
- Edición del archivo `wp-config.php`
- Conexión entre WordPress y la base de datos remota

## Conceptos Clave

- **cPanel:** panel de control web que permite gestionar hosting, dominios, bases de datos y correos.
- **MySQL:** sistema gestor de base de datos relacional utilizado por WordPress.
- **wp-config.php:** archivo de configuración principal de WordPress (credenciales de BD, claves de seguridad).
- **phpMyAdmin:** herramienta web para administrar bases de datos MySQL desde cPanel.
- **FTP/SFTP:** protocolos para transferir archivos al servidor remoto.

## Resultado de Aprendizaje

- **RA1:** Evalúa estructura de contenidos de un proyecto digital mediante mapa de navegación.
- **RA2:** Instala administrador de contenidos (CMS) en servidor local para el manejo de datos y desarrollo de sitio web.
- **RA3:** Arma plantilla personalizada en servidor local y remoto considerando criterios técnicos de diseño.
