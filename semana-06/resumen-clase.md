# Semana 06 - Creando Contenidos y Bucles Personalizados

**Experiencia:** 3 | **Asignatura:** Administración de Contenidos

---

## Introducción

Esta semana se ingresa al mundo avanzado de WordPress: Custom Post Types (CPT) y Custom Loops. Los CPT permiten crear tipos de contenido más allá de las entradas y páginas estándar, mientras que los Custom Loops permiten mostrar ese contenido de formas únicas y adaptadas. También se revisan medidas de mantenimiento y seguridad del sitio.

---

## Temas Tratados

- ¿Qué es un Custom Post Type (CPT) de WordPress?
- Registro de un CPT mediante `register_post_type()`
- ¿Qué es un Custom Loop de WordPress?
- Creación de bucles personalizados con `WP_Query`
- Habilitar el editor de bloques Gutenberg para un CPT
- Medidas de mantenimiento y seguridad en WordPress

## Conceptos Clave

- **Custom Post Type (CPT):** tipo de contenido personalizado registrado en WordPress (ej. portafolio, productos, eventos).
- **register_post_type():** función PHP para declarar un CPT con sus parámetros.
- **Custom Loop / WP_Query:** clase que permite hacer consultas personalizadas a la base de datos de WordPress.
- **Gutenberg:** editor de bloques nativo de WordPress.
- **Nonce de seguridad:** token que protege formularios y peticiones en WordPress contra CSRF.
