## ¿Qué es WordPress?

WordPress es una plataforma de gestión de contenidos (CMS) ampliamente utilizada para crear y administrar sitios web y blogs. Actualmente impulsa más del **41% de los sitios web de todo internet**, desde blogs personales hasta sitios empresariales complejos.

---

## WordPress.com vs WordPress.org

Estas dos plataformas comparten el mismo software base pero difieren en alojamiento y control:

### WordPress.com
- Plataforma de alojamiento gestionada por **Automattic**.
- Ideal para usuarios que desean una solución fácil, sin preocuparse por la administración técnica.
- Versión gratuita con limitaciones: **no permite insertar CSS, JS ni HTML propio**.
- Las actualizaciones técnicas se gestionan automáticamente.

### WordPress.org
- Proporciona el software de código abierto para instalar en tu **propio servidor**.
- Control total: puedes instalar plugins, temas de terceros y modificar el código fuente.
- Permite insertar librerías JS, CSS y tu propia estructura HTML.
- La responsabilidad de actualizaciones, seguridad y alojamiento es tuya.

## Panel de Administración de WordPress

Al crear tu cuenta en wordpress.com, accedes al panel de administración con **16 secciones clave**:

| Sección | Función |
|---------|---------|
| **Estadísticas** | Tráfico del sitio, visitas, fuentes y contenido popular |
| **Mejoras** | Dominios personalizados, opciones de diseño, almacenamiento |

| **Entradas** | Crear, editar y gestionar posts del blog |
| **Medios** | Almacenamiento de imágenes, videos y documentos |
| **Páginas** | Páginas estáticas del sitio (inicio, contacto, etc.) |
| **Comentarios** | Moderación y respuesta a comentarios |
| **Formularios** | Creación de formularios de contacto y encuestas |
| **Jetpack** | Plugin multifuncional: estadísticas, seguridad, imágenes |
| **WooCommerce** | Funcionalidad de comercio electrónico |
| **Apariencia** | Cambiar tema, diseño y widgets |
| **Plugins** | Gestión de plugins disponibles para tu plan |
| **Usuarios** | Roles y permisos de colaboradores |
| **Herramientas** | Importar/exportar datos, enlaces personalizados |
| **Ajustes** | Configuración general: título, descripción, permalinks |
| **Cerrar menú** | Liberar espacio en pantalla durante la edición |

## Estructura de Contenidos en WordPress

WordPress organiza el contenido en dos grandes tipos:

### Entradas (Posts)
- También llamadas **«posts»** o **«artículos»**.
- Publicaciones que aparecen de forma **cronológica** en el sitio.
- Cada entrada es única y representa un artículo, noticia u opinión.
- Se organizan mediante **categorías**, **etiquetas** e **imágenes destacadas**.
- Para crear una nueva: `Entradas > Añadir nueva entrada`.

### Páginas
- Representan secciones **estáticas** del sitio.
- Contenido permanente que raramente cambia: inicio, "Acerca de", "Contacto".
- **No** se organizan cronológicamente como las entradas.
- Se gestionan desde `Páginas` en el panel de administración.

## El Editor de WordPress (Bloques)

El editor de WordPress funciona con **bloques**: unidades de contenido individuales para texto, imágenes, videos u otros elementos.

### Elementos clave del editor:
1. **Ícono de wordpress.com** → Regresa al panel de administración general.
2. **Título** → Primera parte visible de la publicación (usa H1 solo aquí).
3. **Bloques de contenido** → Añade texto, imágenes, videos. Usa encabezados H2–H6 para estructurar.
4. **Resumen de publicación** → Estado, template visual, hora y privacidad.
5. **Extracto** → Descripción breve de la entrada.
6. **Categorías** → Organiza el contenido para la navegación de usuarios.
7. **Imagen destacada** → Portada que aparece en listados y página de inicio.
8. **Publicar** → Hace visible el contenido en el sitio.

> ⚠️ **Importante:** Después de publicar una entrada, debes también **"Publicar sitio"** para que sea visible en línea. De lo contrario, el contenido no estará disponible para los visitantes.

---

## Publicando tu Primera Entrada

1. Crea el contenido en el editor de bloques.
2. Asigna un **título significativo**.
3. Selecciona una **categoría**.
4. Añade un **extracto** descriptivo.
5. Elige una **imagen destacada** atractiva.
6. Haz clic en **"Publicar"**.
7. Luego haz clic en **"Publicar sitio"** desde la barra superior.

## Introducción

WordPress es un Sistema de Gestión de Contenidos (CMS) que permite crear, gestionar y publicar contenido en línea de manera eficiente. Originalmente diseñado para blogs, hoy impulsa más del 41% de los sitios web en internet. En esta semana se distingue entre wordpress.com y wordpress.org y se da el primer acercamiento a la plataforma.

## Conceptos Clave

- **CMS (Content Management System):** sistema que permite gestionar contenido web sin necesitar código.
- **WordPress.com:** plataforma alojada y administrada por Automattic.
- **WordPress.org:** software libre que se instala en servidor propio.
- **Entradas (Posts):** publicaciones cronológicas del blog.
- **Bloques (Gutenberg):** unidades de contenido del editor visual de WordPress.
